Я инженер по тестированию с опытом 7 месяцев в обеспечении качества веб‑ и мобильных приложений. Выбрала эту профессию, потому что мне нравится разбираться в деталях, находить неочевидные сценарии и делать продукты удобнее и надёжнее для пользователей.

На предыдущих проектах я:

* выявляла и документировала дефекты;
* тестировала кросс‑браузерную и кросс‑платформенную совместимость;

## Навыки и инструменты

**Виды тестирования:**
* функциональное;
* регрессионное;
* смоук;
* кроссбраузерное и кроссплатформенное;
* юзабилити;
* нагрузочное (базовый уровень);
* тестирование API.

**Техники тест‑дизайна:**
* классы эквивалентности;
* анализ граничных значений;
* попарное тестирование (pairwise);
* таблицы принятия решений.

**Инструменты и технологии:**
* **тестирование API:** Postman, REST API;
* **отладка и анализ:** DevTools (вкладка Network, Elements, Console, эмуляция устройств);
* **баг‑трекинг:**  YouTrack;
* **управление тест‑документацией:** TMS, Google Таблицы, TestRail;
* **дизайн‑макеты:** Figma (сверка интерфейса с макетами);
* **форматы данных:** JSON, XML;
